# Pickup Simulator

Status: placeholder.

This tool will generate or control repeatable pickup-like events for firmware and bench testing.

Initial goals:

- Simulate single-cylinder 2-stroke RPM sweeps.
- Simulate cranking, idle, acceleration, deceleration, and rev limiter regions.
- Inject missing pulses and noisy pulses for fault tests.
- Record expected trigger timing for comparison.

This comes before engine testing.
