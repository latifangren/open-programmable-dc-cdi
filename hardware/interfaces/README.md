# Hardware Interfaces

This folder documents boundaries between boards and external systems.

Initial interface list:

- Pickup sensor to Controller Board.
- Controller Board to CDI Power Board trigger command.
- CDI Power Board to Controller Board Vcap feedback.
- CDI Power Board to Controller Board fault status.
- 12V input and ground strategy.
- CDI coil output.

Open decisions:

- Connector type.
- Pinout.
- Isolation strategy.
- Signal voltage levels.
- Safe default states.
