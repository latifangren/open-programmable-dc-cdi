# Engine Profiles

Status: placeholder.

This folder is for engine profile metadata.

Profiles may describe:

- Engine cycle: 2-stroke or 4-stroke.
- Cylinder count.
- Displacement class.
- Pickup type.
- Pickup offset.
- Safe RPM limits.
- Coil and plug assumptions.

Initial profiles should stay generic for under-200cc single-cylinder 2-stroke engines.
