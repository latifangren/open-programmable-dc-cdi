# Calibration

Status: placeholder.

This folder is for ignition maps, engine profiles, and calibration metadata after safe formats exist.

No calibration file here is production advice unless backed by bench and engine test reports.

Initial scope:

- Small single-cylinder 2-stroke engines under 200cc.
- Generic profiles before brand-specific profiles.
- Conservative defaults only.

4-stroke profiles may be added later after the scheduling model supports them explicitly.
