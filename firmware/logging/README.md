# Logging

Status: placeholder.

This folder is for firmware logging contracts and formats.

Minimum useful bench logs:

- Timestamp.
- RPM.
- Pickup period.
- Requested advance.
- Scheduled trigger time.
- Actual trigger time if measurable.
- Vcap.
- Charger state.
- Fault reason.

Logging must support bench validation before feature dashboards are built.
