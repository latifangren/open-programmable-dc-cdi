# Engine Tests

Status: blocked.

Engine tests are not allowed until bench validation passes.

Before anything is added here, the project must have:

- HV safety review complete.
- Bench discharge validation complete.
- Timing validation complete.
- Fault handling validation complete.
- Clear emergency shutdown procedure.

Initial engine scope, when allowed, is small single-cylinder 2-stroke engines under 200cc. 4-stroke tests are future work.
