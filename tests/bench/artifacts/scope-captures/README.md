# Scope Captures

Status: placeholder. No scope captures are recorded yet.

This folder is for future oscilloscope, logic-analyzer, and timing captures from controlled bench tests.

Every capture should record:

- report ID and test ID,
- instrument model,
- probe type and rating,
- channel labels,
- vertical and horizontal scale,
- trigger settings,
- grounding or isolation method,
- Vcap state before and after the test where relevant.

HV secondary probing must not use unsafe direct probing. Captures are not validation evidence until linked from a reviewed report.
