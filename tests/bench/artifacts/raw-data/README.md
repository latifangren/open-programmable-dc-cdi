# Raw Bench Data

Status: placeholder. No raw bench data is recorded yet.

This folder is for future unprocessed measurement files, photos, setup images, instrument exports, and supporting data from bench tests.

Raw data must remain attached to a report ID and test ID. Summaries, pass/fail decisions, and safety conclusions belong in `../../../reports/`, not only in this folder.

Do not add edited images or derived plots without keeping the original capture or export when practical.

Engine, vehicle, or road-test data does not belong here. Engine testing remains blocked until bench reports prove the required behavior.
